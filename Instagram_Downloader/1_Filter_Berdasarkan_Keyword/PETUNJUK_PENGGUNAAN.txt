PANDUAN SINGKAT: INSTAGRAM MEDIA DOWNLOADER
============================================================
1. Buka BUKA_INPUT_TARGET.bat (input_target.txt).
2. Tentukan pengaturan:
   - TARGET_AKUN   : Masukkan 1 atau banyak tautan / username akun target.
   - DARI_TANGGAL  : Batas tanggal awal (format: YYYY-MM-DD, contoh: 2026-01-01).
                     (Kosongkan jika ingin mengunduh tanpa batas awal).
   - SAMPAI_TANGGAL: Batas tanggal akhir (format: YYYY-MM-DD, contoh: 2026-12-31).
                     (Kosongkan jika ingin mengunduh hingga postingan terbaru).
   - KEYWORDS      : Kata kunci caption (KOSONGKAN jika ingin mengunduh SEMUA postingan).
   - HASHTAGS      : Tagar caption (KOSONGKAN jika ingin mengunduh SEMUA postingan).
   - MAKSIMAL_POST : Batas post per akun (isi 0 untuk semua postingan).
   - SIMPAN_CAPTION: ya / tidak (default: tidak).
3. Simpan file (Ctrl+S), lalu klik 2x JALANKAN_DOWNLOADER.bat.
4. Media hasil unduhan akan tersimpan di folder Hasil_Download\<username>\.

Tips & Fitur Login:
- Mendukung download SEMUA postingan akun target secara otomatis.
- Mendukung filter rentang waktu tertentu.
- Jika akun target privat atau dibatasi usia/sensitif, jalankan LOGIN_AKUN.bat
  atau BUKA_NOTEPAD_LOGIN.bat untuk memasukkan sesi cookies Instagram Anda.
============================================================
