# ThisVid Video Downloader

Pengunduh video otomatis untuk `thisvid.com` berbasis Python & `yt-dlp`. Mendukung pengunduhan massal (batch) dari berkas Notepad, anti-duplikat, serta penanganan cookies untuk konten restricted/member.

## Berkas & Fungsi

* **`BUKA_NOTEPAD_LINK.bat`**: Membuka `link_video.txt` untuk menempelkan daftar URL video.
* **`DOWNLOAD_SEKARANG.bat`**: Menjalankan skrip `downloader.py` untuk mengunduh semua tautan.
* **`BUKA_NOTEPAD_COOKIE.bat`**: Membuka `input_cookie.txt` jika diperlukan autentikasi akun.
* **`Hasil_Download/`**: Folder tempat video MP4 tersimpan.
* **`download_history.txt`**: Riwayat ID video agar tidak diunduh ulang.
